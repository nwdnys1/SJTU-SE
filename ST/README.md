# ST（软件测试）

- 包含课件、4 份作业
- 课程笔记见[个人博客](https://blog.nwdnysl.site/2025/02/19/%E8%AF%BE%E7%A8%8B%E7%AC%94%E8%AE%B0/ST/)

## HOMEWORK

- HW1：黑盒测试 针对某一个 LLM 应用设计文本生成任务 并设计测试用例进行测试
- HW2：单元测试（白盒测试）选取一个开源项目或自己的课程项目 使用 DD 路径和数据流两种方法进行测试用例的设计 并使用 LLM 辅助测试用例的生成
- HW3：选择一个网页或移动端 app 进行 GUI 测试
- HW4：性能测试 有三个选项 我们选择了部署 LLM 并进行性能测试 包括 TTFT、TPS、TBT 等指标
